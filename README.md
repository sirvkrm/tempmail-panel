# TempMail Engine Control Platform

Coolify-inspired Admin Platform with 3D Connected Living Ecosystem Visualizer for MailMesh.

## Architecture
- **Hierarchical Scopes**: Workspace -> Teams -> Projects (Mobile, Web, Desktop/Bot)
- **Component Switchboard**: Toggle individual endpoints (Play Integrity, FCM Push, POW Challenge, Ad Rewards, Custom Prefix) per project without affecting core mail services.
- **3D Living Ecosystem Graph**: WebGL/Three.js interactive component tree with game-style locked tech nodes for upcoming roadmap modules.
